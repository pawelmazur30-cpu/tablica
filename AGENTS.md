- `index.html` — cała strona; listy wykresów (CHARTS) i paska (TAPE) na górze skryptu.
- Publikacja: GitHub Pages, repo pawelmazur30-cpu/tablica. Zmiana = commit + push, tablet odświeża się sam co 4 h.
